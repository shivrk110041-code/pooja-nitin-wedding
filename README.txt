POOJA & NITIN — ROYAL RAJASTHANI WEDDING INVITATION
===================================================

This is a static, editable website built with plain HTML, CSS and JavaScript.
No framework, build step, package manager, paid API, or subscription is needed.

PREVIEW
-------
Open index.html in a modern browser. Keep the assets folder beside index.html.

PUBLISH FOR FREE
----------------
GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html, LICENSE, README.txt and the complete assets folder.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main / root, and save.

Netlify:
1. Open Netlify Drop.
2. Drag the extracted project folder into the page.

EDITING
-------
- All text, styles, interactions and event cards are in index.html.
- Couple photographs are optimized WebP files in assets/.
- Google Maps link is the one supplied by the family.
- Countdown currently targets 2 December 2026 at 6:00 PM IST. Update the date in the JavaScript if the auspicious lagna time is confirmed differently.
- Fonts load from Google Fonts; system fallbacks are included.
